# 아케이드커피 1층 재오픈 프로젝트 허브

대전 유성구 봉명동 아케이드커피의 2026년 10월 1층 재오픈 준비 자료입니다.
`index.html` 을 열면 시작합니다.

## 페이지

| 파일 | 내용 |
|---|---|
| `brand.html` | 브랜드 방향 — 한 문장 · 색 · 말투 규칙 |
| `index.html` | 전체 요약 |
| `market.html` | 봉명동 상권 실측 |
| `menu.html` | 시그니처 메뉴 8종 · 가격 · 원가 |
| `space.html` | 공간 · 1층 단장 |
| `layout.html` | 동선 · 가구 배치 |
| `procure.html` | 가구 · 조명 조달 |
| `marketing.html` | 마케팅 · 리뷰 |
| `ops.html` | 운영 · 업무 분담 |
| `outlook.html` | 전망 · 리스크와 기회 |
| `settle.html` | 정산 시스템 설계 · 원가 계산기 |

## 만든 방식

- 정적 HTML 10장 + CSS 1장. 빌드 도구 없이 그대로 열립니다
- 사진은 전부 `assets/` 안에 있고 외부 링크를 쓰지 않습니다
- 표는 좁은 화면에서 세로로 풀리고, 사진은 눌러서 크게 볼 수 있습니다

## 자료 출처

수치에는 조사 시점과 출처를 함께 적었습니다.
카카오 로컬 API · 네이버 검색광고 · 네이버 플레이스 원본 · 자사 스마트플레이스 통계를 썼고,
언론·업계 자료는 공신력 등급(1~4급)을 표기했습니다.

메뉴 사진은 실제 촬영본이 아니라 예시 이미지입니다. 시제품 촬영 후 교체합니다.

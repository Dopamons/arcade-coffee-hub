카카오맵 위 경쟁 현황

그림 지도(시장조사 페이지)와 같은 데이터를 실제 카카오맵 위에 올린 화면입니다. 확대·이동이 되고, 점을 누르면 가게 이름이 나옵니다.

지도가 안 보이면 — 카카오 자바스크립트 키가 아직 등록 전입니다.
developers.kakao.com → 기존 앱(카카오 로컬 키를 발급받은 앱) → "앱 키"에서 JavaScript 키를 복사한 뒤, 이 파일(hub/map-live.html) 아래쪽 KAKAO_JS_KEY 자리에 붙여넣습니다. 같은 화면의 "플랫폼 → Web"에 http://localhost:8899를 사이트 도메인으로 추가해야 합니다. REST 키(조사용)와 다른 키이고, 지도 표시용 키는 화면에 노출되어도 도메인 제한으로 보호됩니다.
아케이드커피 카페 (300m 안 28곳) 음식점·술집 (170m 안 45곳 표시)

좌표 출처: 카카오 로컬 API, 2026-07-30 조회 (data/map-places-20260730.json). 지도 재생성이 아니라 좌표 갱신이 필요하면 python scripts/make_map.py를 다시 돌립니다.

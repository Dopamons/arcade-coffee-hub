역할 분담과 표준 체크리스트

잘 돌아가는 카페들이 공통으로 쓰는 표준 운영 체크리스트에 우리 매장 항목을 얹었습니다. 역할마다 "정하는 사람"과 "실행하는 사람"을 나눴습니다 — 실행 담당은 이 목록만 보고 움직이면 되게 만드는 것이 목적입니다.

1

역할 분담

인원은 1층에 모읍니다. 2층은 상주 대신 돌아보기로 관리합니다 (2026-08-01 확정)

사람역할맡는 것
황정인 대표최종 판단방향이 아니다 싶을 때 멈춰 세우는 역할입니다. 실무 권고안대로 이의 없으면 그대로 진행되고, 매주 결재할 것은 없습니다
황헌주 대표1층 운영1층 일일 체크(아래 3장), 바·음료 품질, 원두·재료 거래처, 발주 승인
최규민 매니저홀 운영 + 마케팅 실행1층 홀·계산과 2층 돌아보기(아래 2장), 마케팅 주간 루틴 전체(아래 4장) — 리뷰 답글, 소식 게시, 주간 기록
 원칙: 문안과 기준은 미리 만들어 두고, 실행은 담당자가 목록대로 합니다. "무엇을 할지 고민하는 일"을 실행 담당에게 넘기지 않습니다.
2

인력 배치 — 음료는 1층에서만 만듭니다

2층에는 사람을 세워 두지 않습니다. 인원은 1층 바와 홀에 모읍니다 (2026-08-01 확정)

항목어떻게 합니다
음료 만드는 곳1층 바 한 곳입니다. 2층에는 바를 만들지 않습니다 — 커피머신이 이미 1층 바 카운터 위에 있고(03의 D-08), 2층에 하나 더 두면 기계도 사람도 두 배가 됩니다
주문과 결제2층 손님도 1층 계산대에서 주문합니다. 계단 입구와 2층 각 테이블에 안내를 둡니다
받아 가는 방법호출벨을 받아 올라가시고, 벨이 울리면 1층에서 직접 받아 가십니다. 4인 이상 모임 예약과 잔이 여러 개일 때만 직원이 쟁반으로 올려 드립니다
2층 관리사람을 세워 두는 대신 정해진 시간마다 한 바퀴 돌아봅니다. 주기는 아래 표대로
추가 주문2층에서 더 시키려면 1층으로 내려오십니다. 호출 인터폰은 두지 않습니다 — 부르면 결국 사람이 올라가야 합니다
 왜 올려 드리지 않고 직접 받아 가시게 하나 — 직원이 계단을 한 번 오르내리면 왕복 1~2분입니다. 저녁에 열 번이면 바가 20분 비고, 그 시간이 1층 대기 줄로 돌아옵니다. 2층은 한 번 주문하고 오래 앉는 자리라 올려 드리는 값이 특히 비쌉니다. 계단에서 쏟는 일은 뚜껑과 쟁반으로 줄입니다.

2층 돌아보기 주기

때주기보는 것
낮 (12~18시)1시간마다빈 잔·쓰레기 수거, 테이블 닦기, 화장실, 냉난방
붐비는 시간 (18~22시)30분마다위와 같음 + 빈자리 확인 (1층이 찼을 때 2층으로 안내하려면 몇 자리 남았는지 알아야 합니다)
마감 전 (22시~)1회전체 정리, 창문·조명·냉난방, 테라스 컵 수거
 돌아보기는 그 시간 홀 담당이 맡습니다. 한 바퀴에 5분 안쪽입니다. 마감분은 아래 3장 마감 목록에 들어 있습니다.

3

매일 — 오픈·마감 체크리스트

담당: 1층 상주 인원 · 2층은 돌아보기로 확인합니다 · 표시된 항목은 우리 매장 특화

오픈 전 (11:30~12:00)

  • 에스프레소 머신 예열 후 추출 테스트 1잔 (맛과 크레마 — 커피 위에 뜨는 갈색 거품 — 확인)
  • 그라인더 분쇄도·1샷 무게 확인 (기준 20g)
  • 우유·생크림·재료 유통기한 확인, 먼저 들어온 것부터 쓰도록 정렬
  • 크림·시럽 미리 제조 — 흑임자 크림 등은 유효 4시간, 오픈분 1회차 제조 (신메뉴 출시 후)
  • 쇼케이스 온도 확인(5도 이하)·진열 — 납품 디저트 도착 검수 포함
  • 시재(잔돈) 확인, POS 개점
  • 테이블·의자·바닥·화장실 상태 확인
  • 간판·조명 점등, 음악 볼륨 (리뷰 불만 이력: "음악이 너무 커서" — 대화 가능한 수준으로)
  • 테라스 상태 확인 (컵·쓰레기·조명)
  • 2층 첫 점검 — 테이블·화장실·냉난방, 안내 카드와 반납대 자리 확인
  • 호출벨 충전·개수 확인 — 수신기 켜기, 벨 15~20개 제자리

마감 (23:00~)

  • 머신 백플러시(세정제 역세척), 스팀완드(우유 데우는 봉)·포터필터(커피 담는 손잡이) 세척
  • 그라인더 호퍼 원두 소진·용기 세척
  • 우유 개봉분 폐기 또는 개봉일 라벨 후 냉장
  • 배치 크림 잔량 전량 폐기 — 다음 날 이월 금지 (유효 4시간 규칙)
  • 냉장·냉동·쇼케이스 온도 기록
  • 시재 마감·POS 정산, 매출 기록
  • 쓰레기 배출, 바닥 청소
  • 21시 이후 판매분 따로 확인 — 나이트캡 잔수 기록 (밤 장사 판정 데이터)
  • 2층 마지막 정리 — 빈 잔 수거, 창문·조명·냉난방, 반납대 비우기
  • 전기·가스·수도 확인, 소등

표준 항목은 카페에서 흔히 쓰는 운영 절차이고, 색 칠한 항목은 우리 메뉴·데이터에서 나온 것입니다. 인쇄해서 바 안쪽에 붙이는 용도로 만들었습니다.

4

매주 — 마케팅 루틴 최규민 매니저

매주 월요일 30분이면 됩니다. 문안은 전부 준비돼 있어서 고민할 것 없이 목록대로 하면 됩니다

  • 5분 기록 — 스마트플레이스에서 세 숫자만 옮겨 적기: 지난주 플레이스 조회수 / 상위 유입검색어 3개 / 새 리뷰 수. 기록처: data/주간플레이스점검.xlsx (노란 칸만 채우면 나머지 자동 계산)
  • 리뷰 답글 — 지난주 새 리뷰 전부에 답글. 문안 틀 8종: 06-marketing/리뷰답글_톤가이드.md에서 골라 쓰면 됩니다
  • 소식 1건 게시 — 플레이스 "소식"에 주 1건 (신메뉴·영업 안내·원두 소개 순환. 문안은 월 단위로 미리 준비해 둡니다)
  • 사진 1장 — 플레이스 사진 탭에 주 1장 업로드 (음료·매장·테라스 순환)
  • 인스타 확인 — 새 DM·댓글 답변만. 게시물 제작은 배정하지 않음 (채널 배분: 플레이스 80 / 블로그 20 / 인스타 0 — 마케팅 페이지 근거)
  • 재고 확인 — 재료·부자재 부족분을 헌주 대표에게 발주 요청
선정 근거 답글 중단(2025-09~)과 지도 유입 급락(-38%)이 같은 시기였습니다. 문안 준비가 끝나 8월 첫 주에 재개합니다. 이 루틴은 그 재개를 매주 끊기지 않게 유지하는 장치입니다. 근거 숫자는 마케팅 페이지에 있습니다.

매월 · 시즌

  • 월 1회 — 주간 기록 4주치 리뷰: 조회수 추세, 검색어 변화, 신메뉴 판매 비중. 결과는 이 허브에 반영
  • 월 1회 — 원두·우유·생크림 단가 확인 (원가율 재계산 — 메뉴 페이지 계산식 기준)

AI 분석운영 체계를 보고 드리는 참고 의견

체크리스트는 처음 2주가 고비입니다. 2주를 넘기면 습관이 되고, 못 넘기면 종이로만 남습니다. 성공 확률을 높이는 방법은 하나 — 매일 같은 시간에, 같은 자리에서 하는 것입니다. 마감 체크는 "불 끄기 직전"처럼 이미 있는 행동에 붙이면 잊기 어렵습니다.

규민 매니저에게는 첫 달에 "잘했는지"를 묻지 말고 "했는지"만 봐 주시길 권합니다. 답글 문안이 어색해도 다는 것이 안 다는 것보다 훨씬 낫고, 품질은 문안 틀이 이미 지켜주고 있습니다. 실행 담당에게 필요한 건 피드백보다 "그거 잘 되고 있네" 한 마디입니다.

나이트캡 잔수 기록은 사소해 보여도 이 프로젝트에서 가장 값진 데이터가 됩니다. 야간 연장이라는 다음 결정이 이 숫자 하나로 정해지기 때문입니다.

이 의견은 마케팅·PM 분석 틀에 이 프로젝트의 실측 데이터를 넣어 나온 참고 의견입니다. 따르셔도 되고 안 따르셔도 됩니다 — 판단은 대표님들 몫입니다.
